Changelog

1.0.0

Major update

Added

  • Smooth posing: hands blend in and out of poses
  • Custom hands support (bones matched by name, any rig)
  • Smoother hands that respond better (predicted targets, locked mass properties)
  • More realistic rig that doesn't bounce
  • Left hand posing support
  • Mirror posing (WIP, enable it in VRPF Settings)
  • Full body IK, plus Auto Set Full Body IK
  • Guns rebuilt with HurricaneVR-style reloading: chamber, magazine wells, slide lock, eject and slide release buttons, charging handles, casing ejection, recoil
  • New gun example (SMG) and gun prefabs (Makarov with suppressor, AK-47, SMG)
  • Updated the Grabbable setup window to a simpler version
  • Setup Tool is way more advanced: checklist, OpenXR setup, player builder, gun creator, posing tools, full body IK
  • New grab scripts, new socket system, new rig scripts and framework
  • Device Simulator for testing without a headset
  • Much more documentation: a page for every component

Changed

  • Not using the XR Interaction Toolkit anymore (XR Plug-in Management + OpenXR only)
  • Movement is as smooth as Marrow (acceleration, slope glue, step assist)
  • Reorganized player scripts into VR Physics Framework/Framework/Player
  • Renamed the "VRPF guns" folder to "Gun Examples" and moved it to the "Interactables" folder
  • Rewrote some of the code; old scripts (Physics Rig, Physics Based Movement, Hand Presence, Hand Presence Physics, Hand Pose Player, Damageable) were ported, not replaced

Removed

  • The non-physics rig
  • The XR Interaction Toolkit starter assets

Fixed

  • Setup tool
  • Grabbables making the player fly on grab
  • Guns that didn't shoot
