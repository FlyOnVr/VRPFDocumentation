Reference

Components

Every component in VR Physics Framework 1.0.0, what it does, and how to use it. Each one has its own page with all of its settings.

Core

Input, settings and editor testing.

Scripting API

VRPF Input

Reads both controllers straight from XR Plug-in Management (UnityEngine.XR.InputDevices). No XR Interaction Toolkit, no Input System actions.

Open →
Settings Asset

VRPF Settings

Project-wide settings: grip/trigger thresholds, pose blending, mirror posing (WIP), the device simulator and debug logging.

Open →
Component

VRPF Device Simulator

Test in the editor without a headset: mouse look, WASD movement, and keyboard controls for both hands.

Open →

Player

The physics rig, movement, tracking and hands.

Component

Physics Rig

The player: a capsule Rigidbody body that follows your real-world walking, keeps the headset above it, and gives the physics hands their targets.

Open →
Component

Physics Based Movement

Smooth (Marrow-style) thumbstick locomotion, smooth or snap turning, and button or arm-swing jumping for the Physics Rig.

Open →
Component

VRPF Tracked Pose

Drives a transform from the headset or a controller using XR Plug-in Management. Replaces Tracked Pose Driver.

Open →
Component

Hand Presence Physics

A physics hand: a Rigidbody that chases its controller with velocity, collides with the world, and carries whatever it holds.

Open →
Component

Hand Presence (Hand Animator)

Animates a hand model from the controller's trigger and grip (Animator float parameters "Trigger" and "Grip").

Open →
Legacy Component

Animate Hand On Input (Legacy)

The 0.2 Input System hand animation script, kept so old prefabs keep working. It now behaves exactly like Hand Presence.

Open →

Interaction

Grabbing, grab points and sockets.

Component

VRPF Grabbable

Makes an object grabbable by the physics hands. Needs a Rigidbody (on itself or a parent) and colliders.

Open →
Component

VRPF Grabber

Lets a physics hand grab things: finds the closest grabbable or grab point around the palm, lines the hand up, blends the pose and locks the object to the hand.

Open →
Component

VRPF Grab Point

A place on a grabbable where a hand goes, with optional ghost hand poses for each hand.

Open →
Component

VRPF Socket

A place items snap into: holsters, magazine wells, attachment points, key slots. Items need a VRPF Socketable.

Open →
Component

VRPF Socketable

Marks a grabbable as something that fits in sockets, with a type the socket filters by.

Open →
Component

Requires Parent Grab

Only lets a child grabbable be grabbed while its parent is held (slides, charging handles, bolts, lids).

Open →
Component

VRPF Respawn On Fall

Puts an object back where it started if it falls out of the world (or is left lying far away).

Open →

Posing

Hand skeletons and smooth hand poses.

Component

Hand Bone Data

Describes a hand skeleton (root + bones). Used on hand models and on the ghost "poser" hands you pose on objects.

Open →
Component

VRPF Hand Poser

Smooth posing: blends the hand's fingers into a ghost pose (and back) over a short time, on top of the Animator.

Open →
Component

Hand Pose Player

The 0.2 pose component, ported: put it on a grabbable with a posed ghost hand and the hand blends into that pose when grabbed.

Open →

Weapons

Guns, magazines, slides, ejection and damage.

Component

VRPF Gun

A physical gun with HurricaneVR-style handling: chamber, magazines, slide/charging handle, slide lock, eject and slide release buttons, ejection, hitscan bullets, recoil and sounds.

Open →
Component

VRPF Magazine

Ammo container that goes into a gun's magazine socket.

Open →
Component

VRPF Magazine Socket

The magazine well. A VRPF Socket set up like HurricaneVR: magazines are taken from your hand and slide in; the eject button drops them out.

Open →
Component

VRPF Charging Handle

A charging handle or pistol slide you grab and pull back (HurricaneVR style).

Open →
Component

VRPF Gun Part

A moving gun part (slide, bolt, hammer, trigger) that moves between its rest pose and a "back" pose.

Open →
Component

VRPF Ejector

Spits out spent casings or unfired rounds from the ejection port.

Open →
Component

Damageable

Health for anything that can be shot. Ported from 0.2: hit counting became health, with ragdoll, hit force, destroy and events.

Open →

Full Body IK

Humanoid avatars that follow the player.

Component

VRPF Full Body IK

Full body IK for any humanoid avatar using Unity's built-in humanoid IK (no extra packages).
