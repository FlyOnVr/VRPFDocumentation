VRPF Input

Reads both controllers straight from XR Plug-in Management (UnityEngine.XR.InputDevices), with no Input System actions to set up.

ScriptFramework/Core/VRPFInput.cs

Overview

VRPF Input is created automatically when you press Play. It polls the left and right controllers once per frame, before any other script, so every component sees the same button states.

Each controller is a VRPFController with analog values (Trigger, Grip, Thumbstick), button states with Active, JustActivated and JustDeactivated, device velocity, and haptics. Trigger and grip become buttons using the thresholds in VRPF Settings.

When no headset is running, the Device Simulator (or your own test code) can drive the controllers through VRPFInput.SimulationActive and the Sim* fields.

How to use

  1. You don't add it to anything: it exists as soon as the game runs.
  2. Read a controller with VRPFInput.Left, VRPFInput.Right or VRPFInput.Get(hand).
  3. Use GetButton(VRPFButton.Primary).JustActivated for presses, .Active for holds.
  4. Call Vibrate(amplitude, seconds) for haptics.
C#
using VRPhysicsFramework;

void Update()
{
    var right = VRPFInput.Right;
    if (right.GetButton(VRPFButton.Primary).JustActivated)
        Debug.Log("A pressed");

    float trigger = right.Trigger;          // 0..1
    Vector2 stick = VRPFInput.Left.Thumbstick;
    if (right.TriggerButton.JustActivated) right.Vibrate(0.5f, 0.05f);
}

Scripting

VRPFInput.Left / RightThe two VRPFController instances.
VRPFInput.Get(VRPFHand)Controller for a hand.
VRPFInput.SimulationActiveWhen true, controllers and tracked poses read simulated values.
VRPFInput.SimulatedHeadPose / SimulatedHandPoses[]Simulated poses in tracking space (0 = left, 1 = right).
VRPFController.Trigger / Grip / ThumbstickAnalog values.
VRPFController.TriggerButton, GripButton, PrimaryButton, SecondaryButton, ThumbstickButton, MenuButtonVRPFButtonState with Active, JustActivated, JustDeactivated, Value.
VRPFController.GetButton(VRPFButton)State of a bindable button (used by components with a button setting).
VRPFController.Velocity / AngularVelocityDevice velocity in tracking space.
VRPFController.Vibrate(amplitude, duration)Haptic impulse if supported.
