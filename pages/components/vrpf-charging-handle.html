VRPF Charging Handle

A charging handle or pistol slide you grab and pull back (HurricaneVR style).

WhereAdd Component › VR Physics Framework › Weapons › VRPF Charging Handle
ScriptFramework/Weapons/VRPFChargingHandle.cs
ClassVRPhysicsFramework.VRPFChargingHandle

Overview

Pull it all the way back: the chambered round is ejected and the slide lock is released. Let go: it springs forward and chambers a round from the magazine.

Grabbing a locked-back pistol slide takes it off the slide stop: let go and it slams forward ("slingshot").

The handle follows your real controller along its axis, using the gun's physics pose, so it doesn't jitter even while the gun moves.

How to use

  1. Put it on a child of the gun with a small collider where you'd grab the slide/handle. Its VRPF Grabbable is switched to Hand Follows Object automatically.
  2. Set Pull Direction (parent space), Max Travel, and the Linked Part (the visual slide/bolt).
  3. Add Requires Parent Grab so it can only be racked while the gun is held.
