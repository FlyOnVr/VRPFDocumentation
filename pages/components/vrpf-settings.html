VRPF Settings

Project-wide settings: grip/trigger thresholds, pose blending, mirror posing (WIP), the device simulator and debug logging.

WhereVR Physics Framework > Settings
ScriptFramework/Core/VRPFSettings.cs
ClassVRPhysicsFramework.VRPFSettings

Overview

The settings live in Framework/Resources/VRPFSettings.asset and are loaded automatically. The Setup Tool creates the asset if it's missing.

Mirror posing (WIP) is off by default. Turn it on to let a grab point that only has a right hand pose be used by the left hand (and the other way around). Use the mirror axis and root rotation offset to match your hand rig.

Debug Logging prints every grab, socket and gun state change (magazine inserted, chambered, dry fire and why). Turn it on when a gun "does nothing".

How to use

  1. Open it with VR Physics Framework › Settings.
  2. Adjust thresholds if grabbing feels too sensitive or too stiff.
  3. Turn on Debug Logging while setting up guns, off for builds.
