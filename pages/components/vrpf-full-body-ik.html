Full Body IK · Component

VRPF Full Body IK

Full body IK for any humanoid avatar using Unity's built-in humanoid IK (no extra packages).

WhereSetup Tool › Full Body IK › Auto Set Full Body IK
ScriptFramework/IK/VRPFFullBodyIK.cs
ClassVRPhysicsFramework.VRPFFullBodyIK

Overview

Places the avatar under the headset, turns the body when the head turns past a threshold or you move, crouches the hips, reaches the hands to the physics hands, aims the head with the camera, and steps the feet procedurally.

The Animator needs a controller with IK Pass enabled; Auto Set creates one.

By default the avatar's own hands are hidden and the VRPF physics hands are shown at the wrists.

How to use

  1. Make sure your character's model is imported as Humanoid (Rig › Animation Type › Humanoid).
  2. Open Setup Tool › Full Body IK, assign the avatar and the player, click Auto Set Full Body IK.
  3. If the wrists look twisted, rotate the "IK Target" objects under each physics hand.
  4. Tweak Head Offset so the neck sits right, and Avatar Eye Height if auto calibration is off.
