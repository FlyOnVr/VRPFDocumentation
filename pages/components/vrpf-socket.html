VRPF Socket

A place items snap into: holsters, magazine wells, attachment points, key slots. Items need a VRPF Socketable.

WhereAdd Component › VR Physics Framework › Interaction › VRPF Socket
ScriptFramework/Interaction/VRPFSocket.cs
ClassVRPhysicsFramework.VRPFSocket

Overview

Detection is by distance along the insertion path (Entry Offset → Attach Point), so no trigger collider is needed.

On Release: drop the item near the socket. While Held: the socket takes the item out of your hand as soon as it's close and lined up (how magazines work).

Inside the Approach Radius an accepted item stops colliding with the socket's owner (like an open magazine well), so it can be lined up without bumping the gun.

Socketed items are parented to the attach point and made kinematic, slide in along the entry path, and collide with nothing on the owner. Grab them out, call Release(), or eject them.

How to use

  1. Add the component to an object, set the Attach Point (where the item ends up) and Accepted Types.
  2. For a slide-in motion, set Entry Offset to where the item starts (attach point axes, meters).
  3. Optionally give it a Starting Item (scene object or prefab).
