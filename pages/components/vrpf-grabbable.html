VRPF Grabbable

Makes an object grabbable by the physics hands. Needs a Rigidbody (on itself or a parent) and colliders.

WhereVR Physics Framework › Create › Make Selected Grabbable
ScriptFramework/Interaction/VRPFGrabbable.cs
ClassVRPhysicsFramework.VRPFGrabbable

Overview

Without grab points, the hand grabs wherever it touches (dynamic grab). Add Grab Points for fixed hand positions and poses.

Attach Mode: Joint locks the object to the hand with a joint (props, guns). Hand Follows Object uses no joint; the hand follows the object instead (slides, charging handles, levers, kinematic objects).

Pull Mode decides what moves when a posed grab lines up: light free objects fly into the hand; heavy, kinematic or jointed objects pull the hand to them. Auto picks for you.

While held, the object ignores collisions with your body and the holding hand. That's the fix for "Grabbables making the player fly on grab".

Throwing uses the hand's averaged velocity, including spin.

How to use

  1. Select objects and use VR Physics Framework › Create › Make Selected Grabbable (or the Setup Tool's Grabbable tab). It adds a Rigidbody, a convex collider if needed, the component, and sets the Grabbable layer.
  2. Optionally add grab points as children.
  3. Use the events (or the C# Grabbed/Released events) to react to grabs.
C#
var grabbable = GetComponent<VRPFGrabbable>();
grabbable.Grabbed += (g, hand) => Debug.Log($"Grabbed by {hand.Hand}");
grabbable.Released += (g, hand) => Debug.Log("Dropped");

// Block grabbing with your own rule:
public class OnlyWhenPowered : MonoBehaviour, IVRPFGrabCondition
{
    public bool powered;
    public bool CanBeGrabbed(VRPFGrabber grabber) => powered;
}
