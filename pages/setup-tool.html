Setup Tool

VR Physics Framework › Setup Tool. One window for configuring the project and building everything the framework uses.

Project

Run Full Setup configures layers, the collision matrix, physics and time settings, the settings asset and OpenXR for PC and Quest. The checklist below it shows what's already done, with a Fix button per line. Body ignores grabbables controls whether your body capsule passes through props (on by default, like 0.2).

Player

Create VRPF Player In Scene builds the whole rig. Assign your own left/right hand model prefabs for custom hands: the tool adds Hand Bone Data (bones detected automatically), a Hand Poser, Hand Presence, puts the colliders on the hand layers and places the palm. Use the offsets to line the model up with the controller. Replace Hand Models On Selected Player swaps hands on an existing player.

Grabbable

The simpler 1.0 version: select objects, set a mass, click Make Grabbable. Add Grab Point adds a grab point with optional right and left ghost hands to pose.

Posing

  • Auto-Detect Hand Bones: adds Hand Bone Data to any hand model (custom hands).
  • Create Poser Prefab: makes a ghost hand prefab from one of your player's hands, so poses line up perfectly with your custom hands.
  • Mirror Right → Left / Left → Right (WIP): creates the other hand's ghost by mirroring a pose. The Runtime mirror posing toggle lets missing poses be mirrored in play mode.

Guns

Drag a gun model into the scene, assign it here with its magazine, slide/bolt, optional charging handle and trigger parts, choose which axis the barrel points along, the ammo type, capacity, fire rate, damage, fire modes and sounds, then Build Gun. You get a gun prefab and a magazine prefab in Gun Examples/Prefabs. Fine-tune the Grip, Muzzle, Magazine Well, Charging Handle and Ejection Port children afterwards. See Guns & Reloading.

Full Body IK

Assign a humanoid avatar and the player, then Auto Set Full Body IK. Options: hide the avatar's hands (show VRPF hands), scale the avatar to the player's eye height. See Full Body IK.
