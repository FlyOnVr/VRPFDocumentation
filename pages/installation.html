Installation

Import the framework, run one setup button, and you're ready to build.

Requirements

PackageVersionNotes
Unity6000.0 or newerTested on 6000.0.74f1.
Universal Render Pipeline17+The tech demo uses URP materials.
XR Plug-in Management4.xcom.unity.xr.management
OpenXR Plugin1.xcom.unity.xr.openxr. The provider that talks to your headset.
Input System1.x (optional)Only used by the keyboard/mouse Device Simulator.

Import

  1. Open your project (or create a new Universal 3D project).
  2. Install OpenXR Plugin from Window › Package Manager › Unity Registry. XR Plug-in Management comes with it.
  3. Import the VR Physics Framework package (or copy the VR Physics Framework folder into Assets).

Project setup

Open VR Physics Framework › Setup Tool, stay on the Project tab and click Run Full Setup. It:

  • creates the layers Grabbable, Left Hand Physics, Right Hand Physics and Body;
  • sets the collision matrix so hands and body ignore each other (and, optionally, the body ignores grabbables);
  • applies physics settings (solver iterations 25/15, no auto sync) and 100 Hz physics;
  • creates the VRPF Settings asset;
  • enables the OpenXR loader for PC and Android and turns on the Oculus Touch (and Meta Quest Touch Pro/Plus) interaction profiles, plus Meta Quest Support on Android.

The checklist under the button shows every item with a Fix button, so you can run them one at a time.

Spawning in the ground with no hands?
That's almost always a missing OpenXR interaction profile: the controllers never track. Check the two "Oculus Touch interaction profile" lines in the Setup Tool checklist.

Building for Quest

  1. File › Build Profiles: switch to Android.
  2. Run the Setup Tool again (it configures OpenXR for Android too).
  3. In Project Settings › XR Plug-in Management › OpenXR (Android), make sure Meta Quest Support is on.
  4. Use Linear color space, IL2CPP and ARM64 as usual for Quest.

Troubleshooting

Grabbing does nothing

Make sure the object has a VRPF Grabbable, a Rigidbody and colliders, and that the hand's palm gets within the grab radius (7 cm, or the grab point's radius).

A gun won't fire

Turn on Debug Logging in VRPF Settings. The console says why: no round chambered, slide locked back, or charging handle pulled. Rack the slide or press slide release.

The player slowly slides or bounces

Make sure only the Body capsule is on the Body layer, and that the floor isn't on a layer the body ignores.

The camera doesn't move in the editor

Without a headset the Device Simulator takes over: hold the right mouse button to look.
