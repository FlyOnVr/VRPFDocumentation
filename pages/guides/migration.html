Upgrading from 0.2

1.0 removes the XR Interaction Toolkit. Most 0.2 scripts were ported in place, so their references survive.

Summary

  • XRI is gone. XRI components (XR Origin, XR Grab Interactable, interactors, Tracked Pose Driver) show up as missing scripts. Rebuild the player with the Setup Tool and use VRPF Grabbable for objects.
  • The 0.2 XRI starter assets and the non-physics rig were removed.
  • All runtime scripts live in the VRPhysicsFramework namespace and the VRPhysicsFramework assembly.

Script by script

0.21.0
PhysicsRigPorted: new rig core (body follows the head, no joints, no bounce). Now in Framework/Player.
PhysicsBasedMovementPorted: VRPF input, acceleration, slopes, steps, snap turn. Jump With Hand turns on arm-swing jumping.
HandPresencePhysicsPorted: predicted targets, weight, recoil, locked mass properties. Collider enable/disable API kept.
HandPresence / AnimateHandOnInputPorted to VRPF input; old controller characteristics migrate automatically.
HandPosePlayerPorted to the new grab system; HandPose and MirrorPose values are kept.
HandBoneDataSame component, now with name-based bone matching for custom hands.
VRGunReplaced by VRPF Gun (plus magazines, magazine socket, charging handle, gun parts, ejectors).
DamageablePorted: health, ragdoll, hit force, events. TakeDamage(int) still works.
VRPhysicsAndPosingWindowReplaced by the Setup Tool (VR Physics Framework menu).

Updating scenes

  1. Run Setup Tool › Project › Run Full Setup.
  2. Delete the old rig and XR Interaction Manager; add Create › VRPF Player.
  3. On grabbable objects, remove the missing XR Grab Interactable and add VRPF Grabbable (or use Make Selected Grabbable).
  4. Replace old guns with the new prefabs or build them with the Guns tab.
